# 使用说明

## 开始听讲

双击 start.cmd（macOS / Linux 运行 bash start.sh），网页自动进入本地课堂，无需登录 Sites 或 ChatGPT。在连接设置填写 Gemini 密钥，也可填写本机 .env。获取免费层级密钥的官方链接与四步教程见 README。选择麦克风，使用默认 Live 模式，开始听讲后按浏览器提示允许收音。

英文确认后立即显示和保存，随后出现中文初译；整理完成后，相邻片段可能合成一句，中文可能自动润色。停止后等待余下转写、翻译与保存完成；继续听讲沿用课堂和时间进度，新建课堂建立独立记录。

## 翻译设置

选择 DeepSeek / OpenAI 兼容协议，填写公共 HTTPS 网址、对应密钥与模型。OpenAI 模式支持基础网址或完整端点如 `https://api.example.com/v1/chat/completions`，DeepSeek 使用基础网址。获取列表失败时可手填模型 ID。

多密钥以换行、逗号、中文逗号或分号分隔，自动去重，最多 16 枚，需支持同一接口和模型。并发 1–6，实际不超过密钥数。流式显示进度，思考需提供方支持；OAI 默认兼容设置不传思考控制参数，中转站拒绝显式参数时可恢复默认。

编辑会自动保存在当前浏览器，点击“保存并应用”后用于当前会话。录音或翻译期间不能修改连接。清除设置会恢复默认值；不同浏览器间不共享设置。

## 课堂记录与笔记

课堂记录提供搜索、完整回看、重命名、Markdown 导出和回收站。恢复保留原文、笔记与分析。手写笔记和总结分开；另一窗口更新笔记时，本窗口草稿会附在最新笔记末尾，整理后再次保存。

## AI 助手总结

先启动网页，在“连接总结助手”选择 Codex、Claude Desktop / Code、Cursor、VS Code / Copilot 或通用客户端，复制配置并合并到客户端设置。Windows 也可双击 `mcp-config.cmd` 导出全部配置。首次连接请按客户端提示启用工具，具体位置见 [MCP 接入说明](MCP.md)。

在所选 Agent 中发送网页提供的总结请求，或使用 `summarize_classroom` 模板。Agent 读完全部课堂分页和笔记后生成分析；请求保存时追加到网页“课堂总结”。勾选“只读连接”则只在聊天里展示。MCP 不承担实时翻译，不覆盖个人笔记。ChatGPT 网页版可分析导出的课堂；它不能直接执行本地 stdio 入口。

## 失败恢复

| 提示 | 处理 |
| --- | --- |
| 翻译失败 | 检查网址、密钥、模型及额度，再重试此段 |
| 初译已保留，重试整理译文 | 已有中文保留，排查模型调用后重试整理 |
| 自动保存已暂停 | 保持页面，导出备份；修复后点击重试同步，等待待保存清零 |
| 初译尚未保存 | 先同步再整理；新版同步成功后恢复失败整理 |
| 笔记在其他窗口更新 | 整理合并草稿后再次保存 |
| 麦克风不可用 | 检查浏览器权限、HTTPS / localhost 与设备选择 |

页面有内容不等于服务器已保存；刷新或关闭前确认同步完成。导出的是课堂文本，没有原始音频。
